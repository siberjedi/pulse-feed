API Bağlantıları

API key girildiğinde otomatik test bağlantısı yapılır. Ayarlar bu tarayıcıda localStorage'a kaydedilir.

Notlar

  • Varsayılan endpoint'ler ön-yüklüdür; gerekirse değiştirebilirsiniz.
  • Claude için öneri: https://api.anthropic.com/v1/messages + destekli bir model adı (örn claude-3-5-sonnet-20241022).
  • Claude isteklerinde x-api-key, anthropic-version ve max_tokens zorunludur (kodda uygulanır).
  • Grok için öneri: https://api.x.ai/v1/responses + grok-4.20-reasoning.
  • Llama için sağlayıcınız farklıysa endpoint + model'i kendi servisinize göre güncelleyin.
  • Demo sürümde CORS/politika nedeniyle bazı API'ler tarayıcıdan direkt çağrıda hata verebilir.
  • Proxy bilmiyorsan bu projede hazır var: terminalde npm install ve npm run proxy çalıştır.
  • Sonra Proxy URL alanına şunu yaz: http://localhost:3001/relay?target={url}.
